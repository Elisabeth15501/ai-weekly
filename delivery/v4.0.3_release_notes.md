# AI Weekly Report v4.0.3 — Release Notes

发布日期：2026-09-28
Slug：`ai-weekly` · 版本：`4.0.3` · 许可证：MIT-0（ClawHub 全站强制）

## 一句话总结

v4.0.3 修复综合榜 AA（Artificial Analysis 智能指数）槽位在 `global` 网络环境下无快照兜底的缺陷，**保障周报流水线在海外源不可达时仍能完整生成并通过校验**；功能与 4.0.2 一致。

## 具体变更

### Bug Fix（周报生成健壮性）
- 修复 `scripts/aiweekly/leaderboard.py` 中综合榜 AA 槽位的快照兜底：原先仅当 `detected == "cn"` 才回退 `cn_leaderboard_snapshot.json`，在 `global` 环境下国际源（artificialanalysis.ai）不可达、且本地 cache 的 `aa` 为空时，AA 槽会落空 → 校验 23/25 失败、流水线中断、周报发不出。
- 现改为：综合榜任意一列实时抓取失败且本地 cache 无对应数据时，均回退 `cn_leaderboard_snapshot.json`（标注 `is_cache=True`，如实显示数据截止日），并按 key 精确路由（aa 槽取快照 `"aa"` 键，避免误取 lmarena）。

## 验证

- 合规门禁 `python scripts/compliance_check.py`：exit 0，无 BLOCKER / WARN。
- 单元测试 `pytest scripts/test_p1_guards.py`：11 passed。
- 端到端：以 2026-09-28 周报实测，AA 槽从快照补足 10 行，校验 **25/25 通过**，周报经飞书推送 + gh-pages 部署成功送达。

## 升级方式

直接更新到 v4.0.3 即可。历史周报产物不受影响。
