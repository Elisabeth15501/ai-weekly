# ai-weekly v3.4.0 — SkillHub 评测驱动优化（P0/P1 全部落地）

> 发布日期：2026-09-05
> 前置版本：v3.3.1（2026-09-03，对抗式审查收尾）

本版本对应 [SkillHub 评测优化方案 v2](https://github.com/Elisabeth15501/ai-weekly/wiki/AI-Weekly-SkillHub-Optimization-Plan-v2) 的 P0 阻断级 + P1 体验级全部落地。核心目标：让飞书推送不再依赖 GitHub Pages、让模型数据经得起来源核验、让海外源国内稳定可达、降低新用户学习成本。

## 为什么是 3.4.0

SkillHub 官方评测给出 4.52/5（5 维度均分），明确指出了 5 类问题。配合用户自述痛点（飞书部署依赖 GitHub、海外源国内不稳定、缺对话示例），制定三层优化方案。本版本把 P0（阻断级）和 P1（体验级）全部闭环，进入 P2 完善级。版本号取 `3.4.0`（小版本）：有破坏性体验改善（多后端部署、新约束校验），但向后兼容已有工作流。

## Added

- **P0-1：统一部署分发器**（`scripts/deploy.py`）
  - 支持 6 种后端：`github-pages`（默认）、`tencent-cos`、`vercel`、`netlify`、`cloudflare-pages`、`local`
  - 非 GitHub 后端完全不碰 GitHub，飞书卡片 `view_url` 与部署解耦
  - `publish.py` 新增 `--deploy-to` 参数；`run_report.sh deploy` 改为调 `deploy.py`
  - 附 `delivery/deploy_config.example.json` 配置示例

- **P0-2：模型档案准确性守护**
  - 新增 `scripts/validate_models.py`（`--fix`/`--check`）：清洗 15 条无来源推测条目 → `model_profiles_unverified.json`
  - `model_meta._apply_profile_as_truth` 跳过 `verified=false` 条目，绝不把无来源推测回填榜单
  - `validate_report.py` 新增 `check_model_profiles_accuracy`（校验 24/24 → 25/25 全过）
  - 主表从 72 条 → **57 条全部 `verified=true`**（Claude Opus 5 / GPT-5.6 Sol 等联网核实为真实模型保留）

- **P0-3：海外源国内镜像 + 自动探测**
  - `leaderboard_sources.py` 新增 `URL_REWRITES`（HF/LMArena/AA 主源→hf-mirror 等国内镜像）
  - 新增 `_http_get_fallback`：主源失败→自动回退镜像，全失败抛异常走快照兜底
  - 新增 `scripts/leaderboard_diagnose.py` 诊断工具（逐个源可达性 + 镜像回退命中统计）

- **P1-1：SKILL.md 快速开始**
  - 顶部新增「快速开始」章节，5 个真实对话示例（生成周报/更新排行榜/轻量简报/推送飞书/部署 COS）
  - 更新 6.1 部署章节为多后端写法
  - 更新文件清单登记全部 P0/P1 新增文件

- **P1-2：独立 FAQ 文档**
  - 新建 `references/FAQ.md`（九节 + 排错速查表）：安装配置/首次使用/排行榜/飞书推送/网络/模型数据/成本等
  - SKILL.md 新增 FAQ 入口链接

- **P1-3：交互式飞书配置**
  - 新增 `scripts/init_feishu_config.py`：webhook/connector 双模式交互式创建，含格式/类型/前缀校验
  - `.gitignore` 补 `delivery/feishu_target.json`（含密钥，绝不入库）

- **P1-4：错误提示人性化**
  - 新增 `scripts/aiweekly/errors.py`：ERR-* 错误码体系 + `UserFacingError` 异常类
  - `deploy.py` 关键错误路径改用 `UserFacingError`（含解决步骤）
  - `feishu_connector.py` 缺失依赖错误改用友好提示
  - 日志落盘至 `~/.aiweekly/run.log`

- **P2-1/2：硬约束集中声明**
  - 新增 `scripts/aiweekly/const.py`：所有硬限制常量（新闻上限 100、排行榜 50、HTML 5MB 等）
  - 新增 `scripts/validate_checks/constraints.py`：`check_constraints` 事后审计
  - `validate_report.py` 校验 25/25 → **26/25 全过**（constraints 为 warn 非硬门槛）
  - SKILL.md 第二节.5 新增「硬约束」小节；README「已知限制」补充约束链接

- **P2-3：SkillHub 页面元数据优化**
  - `manifest.json` 版本升至 3.4.0，新增 `features` 字段（10 项核心优势）

## Changed

- **向后兼容**：所有 P0/P1 改动不影响现有工作流，`--deploy`（旧参数）仍可用
- **新闻抓取**：`news.py` 从 `const.py` 重新导出统一常量（不改变行为）
- **验证套件**：25/25 → **26/25 全过**（新增 `check_constraints` 为 warn 级）

## Removed

- 无

## Fixed

- **P0-2**：15 条无来源锚点的推测模型移出主表，避免伪造数据污染榜单
- **P1-4**：部署失败不再输出裸 `RuntimeError("缺少腾讯云 SDK...")`，改为含解决步骤的 ERR-* 错误码
